# Study Buddy v1

## Why this app?
This is a productivity tool I made for myself to help me while studying. I have problems with distractions while studying, this app allows me to study and rather than mindlessly opening programs and letting myself get distracted will keep me focused on the task at hand.  


## How this app works
This is a pomodoro timer that starts with default values of a 50 minute study timer, 10 minute breaks and 4 tudy sessions. This defaults can easily be changed to the users preference.   

<img width="326" height="453" alt="image" src="https://github.com/user-attachments/assets/0fc5b19a-653a-4027-8935-c0e03f4229b3" />  

Users can select programs on their system to block, allowing the user to stay focused on their current task and will only allow the programs on the block list to load once the timer is paused or the break timer is active.   

In the below image steam will be blocked while study timers are active, if the program is open before starting the timer it will be shut down.
